Pack QA Checker02
Backend architecture

ผู้ใช้เห็น Flow เดียว เพราะหลังบ้านรวมทุกแหล่งไว้ใน Model เดียว

Source Adapters

รับ Excel Req, Website OCR, Aztek Tool และ Receipt แยกตามหน้าที่

Canonical Model

จัดข้อมูลเป็น bundle_id / item_id พร้อม value, source, confidence และ locator

Rule Engine

ตรวจความตรงกันข้ามแหล่งและ invariant โดยไม่ผูกกับ Excel หรือ OCR

Report & History

คืน PASS / FAIL / UNVERIFIABLE พร้อมหลักฐานและ revision ที่ตรวจย้อนหลังได้

กฎสำคัญของระบบ: อ่านหลักฐานไม่ชัด → UNVERIFIABLE · พบค่าขัดกับ Spec → FAIL
Pack QA Checker03
Req becomes structured data

วาง Excel ครั้งเดียว ระบบแยก Req ให้ทันที

ระบบรับข้อมูลที่ก๊อบจาก Excel แล้วแยกเป็น Pack parameters และรายการ Item โดยอัตโนมัติ

อ่านทันทีวันเวลา, ราคา, GSP, Limit, Reset และ Pack type
เก็บหลักฐานแนบภาพ Req ให้ PM เปิดดูต้นฉบับได้
ไม่ใช้ OCRลดความคลาดเคลื่อนของข้อมูลที่เป็น ground truth
Pack QA Checker04
Website OCR

ภาพ Website ถูกอ่านเป็นข้อมูลที่เทียบกับ Req ได้

OCR อ่านจากตำแหน่งเฉพาะของแต่ละค่า แล้วเทียบชื่อ Item แบบรองรับคำสลับลำดับและการอ่านคลาดเคลื่อนเล็กน้อย

เลข Amount และ Chance อ่านแยกจากชื่อ เพื่อไม่ให้ค่าหนึ่งที่อ่านพลาดทำให้ทั้งแถวเสีย

การอ่านและประมวลผลทำภายในเครื่องของผู้ใช้

ผลตรวจแยกความผิดจริงออกจากข้อมูลที่ยังต้องให้คนดู เพื่อไม่สร้าง Fail ปลอม

×

FAIL

?

UNVERIFIABLE

อ่านไม่ชัดหรือหลักฐานยังไม่ครบ รอคนยืนยัน

ระบบไม่เติมค่าจาก Spec แล้วอ้างว่า OCR อ่านได้ — ทุกค่าต้องมีที่มาของตัวเอง
Pack QA Checker06
Traceable by design

ทุกผลย้อนกลับไปหาหลักฐานได้

Valueระบบอ่านค่าอะไร
Sourceมาจาก Req, Website, Aztek หรือ Receipt
Confidenceมั่นใจในการอ่านมากน้อยแค่ไหน
Locatorอยู่ที่ Cell หรือภาพตำแหน่งใด

ชื่ออาจต่างภาษาได้ แต่ Pack และ Item ยังจับคู่กันด้วย ID ที่เสถียรกว่า

bundle_id ระบุแพ็ก
item_id ระบุไอเทม

เมื่อพบปัญหา QA สามารถอธิบายได้ว่า “ผิดตรงไหน และเห็นจากอะไร”

Pack QA Checker07
Pack coverage

Flow เดียว รองรับรูปแบบแพ็กที่ทีมใช้จริง

Standard Packตรวจราคา, GSP, Limit และ Item name / amount ตามปกติ
Random Packตรวจ Fixed item และตารางสุ่มจากหลายภาพ พร้อม Chance ของแต่ละ outcome และผลรวม 100%
Permanent Packไม่บังคับวันจบแบบแพ็กทั่วไป และตรวจว่า Aztek Tool ตั้งช่วงเวลาระยะยาวตามเกณฑ์
ระบบเลือกโหมดจากข้อมูล Req อัตโนมัติ ลดการตั้งค่าก่อนเริ่มตรวจ
3
Pack QA Checker08
Supporting evidence

Aztek Tool และ Receipt อยู่ในผลตรวจเดียวกัน

Aztek Tool

OCR อ่านชื่อและวันเวลาเปิด–ปิด พร้อมช่องแก้ด้วยมือเมื่อภาพไม่ชัด

Receipt

แนบเป็นหลักฐานให้ PM เปิดดู ไม่บังคับ OCR เพราะหน้าที่หลักคือยืนยันว่าสินค้าเข้าจริง

เพิ่มได้ทีละรูป สูงสุด 10 รูปต่อการตรวจ
